"올해 건강검진 대상이에요"라는 안내를 받았는데 나도 해당되는지, 작년에 받았는데 또 받아야 하는지 헷갈리죠. 국가건강검진은 **가입 유형** 과 **출생 연도** 로 대상이 정해져요. 기준만 알면 금방 확인할 수 있어요.

## 2026년은 짝수 해 출생자

2년 주기로 받는 검진은 출생 연도의 **짝수·홀수** 로 나뉘어요.

| 해 | 대상 |
| --- | --- |
| **2026년** | **짝수 해** 출생자(1966, 1976, 1986, 1996년생 등) |
| 2027년 | 홀수 해 출생자 |

## 가입 유형별 대상

| 구분 | 대상 | 주기 |
| --- | --- | --- |
| 직장가입자(사무직) | 모든 직장가입자 | 2년에 1회 |
| 직장가입자(비사무직) | 생산·현장직 등 | **매년** |
| 지역가입자 | 세대주, 만 20세 이상 세대원 | 2년에 1회 |
| 피부양자 | 만 20세 이상 | 2년에 1회 |
| 의료급여 수급권자 | 만 20~64세 세대주·세대원 | 2년에 1회 |

사무직인지 비사무직인지는 회사가 공단에 신고한 기준을 따라요. 헷갈리면 인사 담당자에게 물어보세요.

## 나이에 따라 추가되는 검사

기본 검사(키·몸무게·허리둘레, 혈압, 시력·청력, 혈액검사, 소변검사, 흉부 X선 등)에 더해, **특정 나이에 추가되는 검사** 가 있어요.

| 검사 | 대략의 대상 |
| --- | --- |
| 이상지질혈증(콜레스테롤) | 남성 24세 이상, 여성 40세 이상부터 4년마다 |
| B형 간염 | 40세 |
| 골밀도 | 54세, 66세 여성 |
| 인지기능장애 | 66세 이상 |
| 정신건강(우울증) | 20·30·40·50·60·70세 |
| 생활습관 평가 | 40·50·60·70세 |
| 노인신체기능 | 66·70·80세 |

추가 검사 항목과 나이 기준은 해마다 조정될 수 있어요. 본인에게 해당하는 항목은 공단 대상 조회에서 함께 나와요.

## 암검진은 따로 확인해요

일반건강검진과 **암검진은 대상 기준이 달라요.** 위암·유방암·자궁경부암은 2년, 대장암은 매년, 간암은 고위험군 6개월마다예요. 자세한 기준은 [국가 암검진 6종](/checkup/국가암검진-6종-정리/)에 정리해 두었어요.

## 대상 조회하는 법

| 방법 | 경로 |
| --- | --- |
| 모바일 | The건강보험 앱 → 건강검진 → 대상 조회 |
| 누리집 | 국민건강보험공단 누리집 → 건강iN → 검진 대상 조회 |
| 전화 | 1577-1000 |
| 우편 | 연초에 검진표가 발송돼요(주소 확인 필요) |

검진표를 잃어버렸어도 괜찮아요. **신분증만 가지고 가면** 검진기관에서 대상 여부를 확인해 받을 수 있는 경우가 많아요.

## 자주 묻는 것

**작년에 받았는데 올해도 대상으로 나와요.**
비사무직이거나, 작년 검진이 다른 이유로 누락 처리됐을 수 있어요. 공단에 확인해 보세요.

**회사 종합검진을 받았어요.**
종합검진에 국가검진 항목이 포함돼 결과가 공단에 통보됐다면 따로 받지 않아도 되는 경우가 많아요. 공단 누리집에서 수검 처리됐는지 확인하세요.

**직장을 옮겼어요.**
새 직장 기준으로 다시 정해져요. 이직한 해에는 대상 여부가 바뀔 수 있으니 조회해 보세요.

**아이는요?**
영유아는 따로 [영유아 건강검진](/checkup/영유아-건강검진-시기-항목/)을 받아요.

## 한 가족으로 예를 들어 보면

2026년을 기준으로 한 가족을 떠올려 볼게요.

- **1978년생 아빠, 사무직 직장가입자**: 짝수 해 출생이라 2026년이 대상이에요.
- **1981년생 엄마, 아빠의 피부양자**: 홀수 해 출생이라 2027년이 대상이에요.
- **2004년생 첫째, 피부양자(만 20세 이상)**: 짝수 해 출생이라 2026년 대상이에요. 20~30대 피부양자·세대원도 일반검진 대상이라는 걸 모르는 집이 많아요.
- **아빠의 동생, 공장에서 일하는 비사무직 직장가입자**: 출생 연도와 상관없이 **매년** 대상이에요.

이처럼 한 집 안에서도 대상 연도가 제각각이라, 가족 모두 'The건강보험' 앱으로 한 번씩 조회해 보는 게 가장 확실해요. 암검진은 나이 기준이 따로 있어서 같은 해라도 받을 암검진 종류가 사람마다 달라요.

## 대상이라면 이렇게

1. 대상 조회로 **받을 검사 목록** 확인
2. 가까운 검진기관 찾아 **예약** → [검진기관 예약](/checkup/검진기관-예약-직장지역/)
3. 전날 **금식 준비** → [금식 준비](/checkup/건강검진-금식-준비/)
4. 연말엔 붐비니 **10월 안에** 받기

이 글은 일반적인 안내예요. 검진 대상과 항목은 나이와 가입 상태에 따라 달라질 수 있으니, 정확한 안내는 국민건강보험공단(1577-1000)에 확인하세요.
